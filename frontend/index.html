About Me

I am a software engineering student passionate about building real-world applications and solving practical problems using technology. I specialize in full-stack web development using JavaScript, React, and modern databases like MongoDB and PostgreSQL.
I have built multiple projects including an event management system, a tax system prototype inspired by ZRA, a multilingual translator web app, and a weather application. I also independently developed and deployed a Grade 7 educational study game using Netlify and Vercel.
I was part of a team that won 3rd place at the Mukuba Hackathon, where we built a real-time energy management system aimed at improving household electricity usage efficiency.
Currently, I am working on a university learning platform that will help students access past exam questions, study materials, and learning resources.
I am actively seeking internship and collaboration opportunities.
